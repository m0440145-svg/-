# منصة مراسلات

منصة عربية لإدارة الصادر والوارد، وتتبع مسار المعاملات، ومراقبة مدد الاستجابة ومؤشرات الأداء.

## التشغيل

افتح `index.html` مباشرة، أو انشر المستودع عبر GitHub Pages.

## الوظائف الحالية

- لوحة مؤشرات تنفيذية.
- سجل معاملات وفلاتر وبحث.
- خريطة زمنية لمسار المعاملة.
- تسجيل معاملة جديدة ومرفقات.
- تقارير وقوالب وإعدادات الصلاحيات والتكاملات.
- تصميم عربي RTL متجاوب مع الهاتف.
