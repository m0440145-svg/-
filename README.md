# منصة مراسلات — الصادر والوارد

نظام ويب فعلي لإدارة المراسلات والمعاملات في الجمعيات والمؤسسات.

- قاعدة بيانات D1 دائمة للمعاملات والأحداث والملاحظات والقوالب وسجل التدقيق.
- تخزين R2 فعلي للمرفقات حتى 10MB.
- إنشاء المعاملات مع نوعها وأولويتها ومدة الاستجابة.
- رقم هوية اختياري للخطابات الواردة مع التحقق من الصيغة.
- تحويل المعاملة بين الإدارات وتحديث حالتها.
- إضافة الملاحظات ورفع المرفقات.
- بحث وفلاتر تعمل عبر API.
- تصدير تقرير CSV.
- تسجيل المستخدم وIP والعملية والوقت في سجل التدقيق.
- سجل واضح لطلبات API في Console واستجابات فعلية في Network.
